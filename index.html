Cloud Computing

Cloud computing means using computing resources such as servers, storage, databases and software over the internet instead of owning and maintaining them yourself. A provider runs large data centers and rents out capacity on demand, so you pay only for what you use. This makes it easy to start small and scale up when more users arrive. It also reduces the cost of buying hardware and the effort of maintaining it. Because resources are available in many regions, applications can be placed close to users and stay available even if one machine fails. Static websites are a simple first example: the files are stored in the cloud and delivered to anyone with a browser.

Cloud Services

IaaS

Infrastructure as a Service gives you virtual machines, storage and networks that you manage yourself. Example: Amazon EC2.

PaaS

Platform as a Service provides a ready environment to run your code without managing servers. Example: Google App Engine.

SaaS

Software as a Service delivers a finished application through the browser. Example: Google Workspace.
